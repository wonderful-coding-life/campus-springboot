# Spring Boot 코드 리뷰

Spring Boot 프로젝트의 코드를 검토하고 문제점과 개선 사항을 알려준다.

## 리뷰 방법

다음 항목을 확인한다.

- Controller, Service, Repository의 역할이 적절한지 확인한다.
- 의존성 주입을 올바르게 사용했는지 확인한다.
- JPA Entity와 Repository 구현을 확인한다.
- 트랜잭션 처리를 확인한다.
- Validation 처리를 확인한다.
- Spring Security 설정을 확인한다.
- 예외 처리가 적절한지 확인한다.
- 중복되거나 불필요하게 복잡한 코드를 확인한다.

## 리뷰 결과

문제가 있다면 다음 내용을 알려준다.

- 문제가 있는 파일과 위치
- 문제점
- 문제가 되는 이유
- 개선 방법

중요한 문제부터 알려준다.

## 주의사항

- 코드를 직접 수정하지 않는다.
- 단순한 스타일 차이는 문제로 지적하지 않는다.
- 실제 코드에서 확인된 문제를 중심으로 리뷰한다.
